# OPEC Knowledge Base (คลังความรู้ระบบ สช.)
> รวบรวมคู่มือทางการและเอกสารสถาปัตยกรรมระบบของสำนักงานคณะกรรมการส่งเสริมการศึกษาเอกชน (สช.)
> จัดเตรียมสำหรับเทรนและเป็นคลังข้อมูลอ้างอิงให้ "น้องฟ้า" (AI Knowledge Base)

---

## สารบัญหมวดหมู่คู่มือ

```
knowledge-base/opec/
├── regis/       # ระบบงานทะเบียนสำหรับโรงเรียนเอกชน (REGIS) - 21 ฉบับ
├── orss/        # ระบบยื่นเรื่องออนไลน์ (ORSS) - 27 ฉบับ
├── psis/        # ระบบบริหารจัดการเงินอุดหนุน (PSIS) - รายงาน อน./อร./อาหารกลางวัน
├── esar/        # ระบบประกันคุณภาพการศึกษา (e-SAR) - รายงาน SAR โรงเรียนสมคิดวิทยา
└── sso/         # ระบบ Single Sign-On กลาง (SSO) - 4 ฉบับ
```

## 2. หมวดระบบยื่นเรื่องออนไลน์ (ORSS)
*ที่มา: เซิร์ฟเวอร์ `orss.opec.go.th` ของ สช. ครอบคลุมการยื่นคำร้องทางราชการ*

### 2.1 งานทะเบียนและผู้สำเร็จการศึกษา (ปพ.3 / รนช.)
1. `การรับและจัดเก็บแบบรายงานผู้สำเร็จการศึกษา (ปพ.3) แบบรายงานการออกประกาศนียบัตรสำหรับโรงเรียนในระบบ ประเภทสามัญศึกษา.pdf` (2.7 MB)
2. `การรับและจัดเก็บแบบรายงานผู้สำเร็จการศึกษาหลักสูตรนานาชาติ (รนช.) สำหรับโรงเรียนในระบบ ประเภทนานาชาติ.pdf` (2.0 MB)

### 2.2 งานแต่งตั้งและถอดถอนบุคลากรทางการศึกษา
3. `การรายงานการแต่งตั้ง-ถอดถอนผู้อำนวยการสำหรับโรงเรียนในระบบ.pdf` (5.5 MB)
4. `การรายงานการแต่งตั้ง-ถอดถอนรองผู้อำนวยการสำหรับโรงเรียนในระบบ.pdf` (4.4 MB)
5. `การรายงานการแต่งตั้ง-ถอดถอนผู้จัดการโรงเรียนในระบบ.pdf` (4.4 MB)
6. `การรายงานการแต่งตั้ง-ถอดถอนครูสำหรับโรงเรียนในระบบ.pdf` (4.2 MB)
7. `การรายงานการแต่งตั้ง-ถอดถอนบุคลากรทางการศึกษาสำหรับโรงเรียนในระบบ.pdf` (4.3 MB)
8. `การรายงานการแต่งตั้งหรือการเปลี่ยนแปลงนายทะเบียนโรงเรียนในระบบ.pdf` (4.6 MB)
9. `การรายงานการแต่งตั้งผู้ปฏิบัติหน้าที่แทนผู้รับใบอนุญาตจัดตั้งโรงเรียนในระบบ.pdf` (2.8 MB)
10. `การรายงานการเปลี่ยนแปลงผู้แทนของผู้รับใบอนุญาตจัดตั้งโรงเรียนในระบบ.pdf` (2.4 MB)
11. `การยื่นคำขอรับครูอาสาสมัครจีนโรงเรียนในระบบ.pdf` (1.9 MB)

### 2.3 งานจัดตั้ง ตราสาร และใบอนุญาต
12. `การขออนุญาตเปลี่ยนแปลงรายการในตราสารจัดตั้งโรงเรียนในระบบ ประเภทสามัญศึกษา.pdf` (6.8 MB)
13. `การขออนุญาตเปลี่ยนแปลงรายการในตราสารจัดตั้งโรงเรียนในระบบ ประเภทนานาชาติ.pdf` (6.4 MB)
14. `การขอโอนและรับโอนใบอนุญาตให้จัดตั้งโรงเรียนในระบบ ประเภทสามัญศึกษา.pdf` (3.4 MB)
15. `การขอโอนและรับโอนใบอนุญาตให้จัดตั้งโรงเรียนในระบบ ประเภทนานาชาติ.pdf` (5.9 MB)
16. `การขออนุญาตเปลี่ยนแปลงรายละเอียดเกี่ยวกับกิจการของโรงเรียนในระบบ ประเภทสามัญศึกษา.pdf` (4.9 MB)
17. `การขออนุญาตเปลี่ยนแปลงรายละเอียดเกี่ยวกับกิจการของโรงเรียนในระบบ ประเภทนานาชาติ.pdf` (4.8 MB)
18. `การขออนุญาตเลิกกิจการโรงเรียนในระบบ ประเภทสามัญศึกษา.pdf` (3.6 MB)
19. `การขออนุญาตเลิกกิจการโรงเรียนในระบบ ประเภทนานาชาติ.pdf` (2.8 MB)

### 2.4 งานบริหารทั่วไปและกิจกรรม
20. `การแจ้งประกาศค่าธรรมเนียมการศึกษาและค่าธรรมเนียมอื่น โรงเรียนในระบบ ประเภทสามัญศึกษา.pdf` (4.1 MB)
21. `การแจ้งประกาศค่าธรรมเนียมการศึกษาและค่าธรรมเนียมอื่น โรงเรียนในระบบ ประเภทนานาชาติ.pdf` (4.2 MB)
22. `การรายงานการอนุญาต และรายงานผลการพานักเรียนไปนอกสถานศึกษาโรงเรียนในระบบ.pdf` (10.9 MB)
