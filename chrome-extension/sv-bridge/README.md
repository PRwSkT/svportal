# SV-Bridge | ตัวช่วยฉีดคะแนนเข้าสู่ระบบ สช. (OPEC REGIS Injector)

**โรงเรียนสมคิดวิทยา**
*เชื่อมต่อผลการเรียนจาก SV Portal เข้าสู่ระบบ สช. (sso.opec.go.th/regis) โดยไม่ต้องพิมพ์คะแนนซ้ำแม้แต่ตัวเดียว*

---

## ฟังก์ชันการทำงาน (Features)
1. **0 Human Error & 0 Duplicate Work:** จับคู่คะแนนนักเรียนจากไฟล์ CSV / JSON ของ SV Portal เข้าสู่ฟอร์มกรอกคะแนนของ สช. อัตโนมัติ
2. **Dual-Layer Auto-Match:** จับคู่ผ่าน **เลขประจำตัวประชาชน 13 หลัก** และ **ชื่อ-นามสกุล** อย่างแม่นยำ
3. **Visual Confirmation:** ไฮไลต์แถวนักเรียนที่ฉีดคะแนนสำเร็จด้วยสีเขียวอ่อน พร้อมสรุปจำนวนนักเรียนที่จับคู่สำเร็จ

---

## ขั้นตอนการติดตั้งบน Google Chrome (Installation)
1. เปิด Google Chrome แล้วไปที่ URL: `chrome://extensions/`
2. เปิดสวิตช์ **Developer mode (โหมดนักพัฒนา)** ที่มุมบนขวา
3. กดปุ่ม **Load unpacked (โหลดส่วนขยายที่คลายแพ็กแล้ว)**
4. เลือกโฟลเดอร์:
   ```
   /Users/peerawatsmacbookpro/Documents/SVPortal-Post/chrome-extension/sv-bridge
   ```
5. ส่วนขยาย **SV-Bridge** จะปรากฏพร้อมใช้งานทันทีบนแถบเครื่องมือของ Chrome!

---

## วิธีการใช้งานจริงร่วมกับ SV Portal (How to Use)
1. เข้าไปที่หน้า **ส่งออกข้อมูล สช. (OPEC Export)** ใน SV Portal (`/academic/opec`)
2. กดปุ่ม **"ดาวน์โหลดไฟล์ CSV สำหรับ สช."**
3. เข้าสู่ระบบ สช. ที่ [sso.opec.go.th/regis](https://sso.opec.go.th) และเปิดหน้ารายวิชาที่ต้องการกรอกคะแนน
4. คลิกไอคอน **SV-Bridge** บนแถบ Extension ของ Chrome
5. เลือกไฟล์ CSV ที่เพิ่งดาวน์โหลดมา
6. กดปุ่ม **"🚀 ฉีดคะแนนลงตาราง สช. (1 คลิก)"**
7. ระบบจะกรอกคะแนนและตัดเกรดลงทุกช่องใน 1 วินาที!
